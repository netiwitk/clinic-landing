# Mellow Dental (เว็บตัวอย่าง)

เว็บคลินิกทันตกรรม 2 ภาษา ทำเป็น portfolio **คลินิกนี้ไม่มีอยู่จริง** ชื่อหมอ ราคา และรูปเป็นของสมมติ (รูปสร้างด้วย AI)

- [Astro 7](https://astro.build) สร้างเป็นไฟล์ HTML สำเร็จรูป (static) วางบน host ไหนก็ได้
- ไม่ส่ง JavaScript framework ไปที่เครื่องผู้ชม มีแค่สคริปต์สั้น ๆ สำหรับฟอร์มจองคิว และสคริปต์เลือกภาษาที่หน้าแรก
- รูปทุกรูปถูกย่อเป็น AVIF/WebP หลายขนาดตอน build มือถือโหลดรูปเล็ก จอใหญ่โหลดรูปใหญ่
- ฟอนต์ Anuphan เก็บไว้ในเว็บเอง ไม่เรียกจาก Google Fonts และโหลดล่วงหน้าเฉพาะชุดตัวอักษรที่หน้านั้นใช้
- หน้า `/` ดูภาษาของเครื่องผู้ชม เครื่องภาษาไทยไปหน้าไทย ภาษาอื่นไปหน้าอังกฤษ
- ฟอร์มจองคิวรวมข้อมูลเป็นข้อความเดียวเพื่อส่งเข้า LINE ของคลินิก ในเว็บตัวอย่างนี้จะแสดงตัวอย่างข้อความแทนการเปิด LINE
- ภาพเคลื่อนไหวทำด้วย CSS ล้วน (การ์ดค่อย ๆ ขึ้นตอนเลื่อนจอ, เปลี่ยนภาษาแบบนุ่มนวล) และปิดเองถ้าเครื่องผู้ชมตั้งค่าลดการเคลื่อนไหวไว้

## รัน

ต้องใช้ Node 24 (Astro 7 ต้องการ Node 22.12 ขึ้นไป)

```bash
nvm use            # สลับไปใช้ Node ตามไฟล์ .nvmrc
npm install
npm run dev        # เปิดดูที่ http://localhost:4321
npm run check      # ตรวจ type และคำแปลที่ขาด
npm run build      # ได้โฟลเดอร์ dist/
```

## ตรวจในเบราว์เซอร์จริง

`scripts/check.mjs` เปิด Chrome แล้วตรวจ: เครื่องไทย/อังกฤษ/ฝรั่งเศสไปหน้าภาษาถูก, ปุ่มสลับภาษา, ฟอร์มจองคิว 2 ภาษา, ไม่มีเลื่อนซ้ายขวาบนจอ 390px, ไม่มี error

```bash
BASE_PATH=/clinic-landing npm run build                # build แบบเดียวกับบน GitHub Pages
mkdir -p /tmp/serve && ln -sfn "$PWD/dist" /tmp/serve/clinic-landing
(cd /tmp/serve && python3 -m http.server 4321 &)       # เปิด server ชั่วคราว
node scripts/check.mjs http://127.0.0.1:4321/clinic-landing/ shots   # shots/ = รูปหน้าจอ
npx lighthouse http://127.0.0.1:4321/clinic-landing/th/ --view     # คะแนนความเร็ว (โหมดมือถือ)
```

## เปลี่ยนรูป

ดู [IMAGE-PROMPTS.md](IMAGE-PROMPTS.md) แล้ววางไฟล์ `.jpg` ทับใน `src/assets/` โดยใช้ชื่อเดิม

## เปลี่ยนข้อมูล

ทุกอย่างอยู่ใน [src/content.ts](src/content.ts)

- ราคา (`services`) และรายชื่อหมอ (`doctors`) ใช้ร่วมกันทั้ง 2 ภาษา
- ข้อความภาษาไทยอยู่ใน `th` ภาษาอังกฤษอยู่ใน `en` ถ้าเพิ่มข้อความใน `th` แล้วลืมใส่ใน `en` คำสั่ง `npm run check` จะแจ้ง error
- LINE ID และเบอร์โทรอยู่ใน `contact` ถ้าใช้กับคลินิกจริง ให้ใส่ LINE ID จริงและตั้ง `demo: false` ปุ่มจองคิวจะเปิดลิงก์ `line.me/R/oaMessage/<LINE ID>/?<ข้อความ>` แทนการแสดงตัวอย่าง (ทางนี้ยังไม่เคยทดสอบกับบัญชี LINE จริง ต้องลองบนมือถือก่อนใช้งาน)
